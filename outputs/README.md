# Outputs

Run `Rscript --vanilla run.R` from the repository root to write these files under `outputs/reproduced/`.

| Location | Contents |
|---|---|
| `tables/manuscript/` | Tables 1 and 2 as HTML and CSV. The separate `table2.csv` contains the contrasts recalculated from the model inputs. |
| `tables/supplementary/` | Tables S1–S29 as HTML and CSV, and the estimates from the activity models. |
| `models/` | The paired heart-rate contrasts and the contributions of timing and speed to the estimated heart-rate response. |
| `figures/manuscript/` and `figures/supplementary/` | The figures for the paper and supplement. |
| `validation/` | Comparisons of recalculated values with Table 2, the paired heart-rate contrasts and selected activity estimates. |
| `sessionInfo.txt` | The R and package versions used for this run. |
