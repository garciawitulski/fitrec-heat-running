# Heart-rate decomposition model statistics

Two additional regressions are needed to calculate the physiological benchmark. The first estimates the change in the temperature gap after adjustment for local start hour. The second estimates the temperature and speed response during steady-speed segments using session temperature and running speed as exposures. The design and outcome files contain whole-cohort cross-products after removing runner effects and nuisance covariates.

The script fits both models and combines their coefficients with the Table 2 estimates for heat avoided, running speed and whole-session heart rate. It evaluates the splines at the cohort reference temperature and speed using the values in `constants.csv`. The percentage reduction compares the predicted rise in heart rate at observed start times and speeds with the rise at a fixed start time and speed. It is calculated as $100(1-R_{\mathrm{observed}}/R_{\mathrm{fixed}})$.

`coefficient_covariance.csv` gives the pooled covariance within the physiological model and between the models of heat avoided with and without start-hour indicators. The delta-method calculation follows the manuscript's covariance specification and holds the other model blocks independent. The two CSV cross-product matrices use per-session averages, which leave their regression coefficients unchanged.
